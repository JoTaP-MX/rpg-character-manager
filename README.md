# RPG Character Manager

Aplicação local para criar, organizar e visualizar personagens, campanhas e
outros conteúdos de RPG, onde cada documento é escrito livremente em Markdown.

## Status
🚧 Em desenvolvimento — veja `docs/RPG_Character_Manager_Arquitetura_v2.md` para arquitetura e decisões.

## Stack
- Backend: Python + Flask + SQLAlchemy + SQLite
- Frontend: React
